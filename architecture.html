🔀 Nginx & TaskView

Ambos os frontends usam nginx:alpine. Requisições em /taskview são encaminhadas diretamente para o container solutis-taskview-prod.

⚡ Real-time SSE & Broker

O Flow Backend despacha mensagens para o Redis 7 e consome via Dramatiq Worker, transmitindo atualizações em tempo real ao TaskView via Server-Sent Events.

🛢️ Bancos Isolados & Core

O Manager Backend e serviços correlatos utilizam MySQL 8.0, enquanto o módulo de governança do Flow possui seu banco isolado PostgreSQL 16.
